#### ⚠️ ATTENTION: THIS MOD DOES NOT ADD ANY FUNCTIONAL BACKPACKS, ONLY VISUAL IN CLIENT-SIDE

## 📖 Overview

**Client Wearables** is a cosmetic mod that adds dynamic visual backpacks;
Replaces existing backpack model from other backpack mods.
This mod is purely **client-side** and does **not** require a server-side installation.

<img src="https://github.com/FaeWulf/public-imgs/blob/main/mods/client_backpack/backpack showcase.png?raw=true" alt="show case 1"/>

## ✨ Features

- **Replace backpack model** from other backpack mod like: sophisticate backpacks, travelers backpacks, inmis backpacks.
- **Dynamic Appearance:** Models and visuals are changed on player's inventory content.
- **Only require in Client-side**
- Works in **single-player** and **multiplayer**.
- Does **not** affect gameplay mechanics, ensuring a fair experience.

## ⛓️‍💥 Compatibility

The mod is designed to be compatible with other mods.
If you encounter any issues, please report them on the
mod's issues tracker.

Current backpack mod that supported:

- Traveler's Backpack
- Inmis
- Sophisticated Backpacks
- Sophisticated Backpacks (Unoffical Fabric port)
